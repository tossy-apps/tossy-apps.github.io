## 🚀 掲載プロダクト

### 1. けんさくくん (KensakuKun)
- **種別**: Windows デスクトップアプリケーション (C# / WPF / .NET 10)
- **概要**: 神Excel・Excel方眼紙・大量仕様書からインメモリで高速全文検索を行う業務支援ツール。
- **LP**: [https://tossy-apps.github.io/kensaku-kun/](https://tossy-apps.github.io/kensaku-kun/)
- **マニュアル**: [https://tossy-apps.github.io/kensaku-kun/help.html](https://tossy-apps.github.io/kensaku-kun/help.html)

### 2. DocReview Studio
- **種別**: Web アプリケーション (完全クライアントサイド実行 / HTML, CSS, JavaScript)
- **概要**: ブラウザ上でローカルのHTML文書を読み込み、レビュー指摘の記録、AI修正指示プロンプトの自動生成、WinMerge風の左右Diff差分検証を行えるドキュメント校正スタジオ。
- **Webアプリ**: [https://tossy-apps.github.io/doc-review-studio/](https://tossy-apps.github.io/doc-review-studio/)
- **GitHub**: [https://github.com/tossy-apps/doc-review-studio](https://github.com/tossy-apps/doc-review-studio)

## 🌟 tossy-apps の開発思想

1. **実務直結の課題解決**  
   実際の現場でボトルネックとなっている神Excelや仕様書調査、ドキュメント校正などの非効率を確実に解決します。
2. **完全オフライン＆安心安全**  
   企業の機密情報や個人情報を扱うツールだからこそ、クラウドへの不要なデータ送信を行わず、ローカル完結で動作します。
3. **AI駆動開発による極限品質**  
   AIエージェント「Antigravity」とのペアプログラミングと厳格なルール定義により、高速かつ妥協のない品質を実現しています。
